# 跑团助手

## 功能介绍

跑团助手是一款由 OpenAI Codex 生成、面向线上文字跑团的本地回复建议工具。它不会自动发送消息，生成的内容始终由玩家确认、修改和使用。

- 为不同模组、场景或角色分别保存规则摘要、场景信息、角色设定、风格偏好与关键词。
- 默认使用专注界面，背景资料编辑器按需打开，不占用日常生成回复的空间。
- 自动识别角色名、别名和自定义关键词，并提供命中统计与上下文高亮。
- 通过独立按钮总结上下文，整理当前局势、已确认事实、人物立场和待确认问题。
- 支持单独设置本轮语气、回复目标、回复模式、篇幅与附加限制，生成可继续修改的大段回复。
- 支持 OpenAI、Anthropic Claude、Google Gemini、DeepSeek、xAI Grok、Mistral、OpenRouter、阿里云百炼 Qwen、Kimi、智谱 GLM 与 MiniMax；模型 ID 可以自行输入，不受内置推荐列表限制。
- 支持自定义 OpenAI Chat Completions 兼容接口，可填写 API Base URL 和模型 ID，接入其他云服务或本地兼容服务。
- 页面自动跟随系统的浅色或深色配色。
- 场景资料保存在本机；API Key 只用于当前运行，不会写入文件。也可使用本地演示模式体验完整流程。

## 如何运行

需要 Node.js 20 或更高版本。在项目文件夹中双击 `start-assistant.cmd`。

- 启动向导会先要求选择运行模式。直接回车默认进入在线模型模式，也可以输入 `2` 进入演示模式。
- 在线模式下依次选择模型服务商、确认或修改模型 ID，再隐藏输入一次性 API Key。选择自定义兼容接口时还可以填写 API Base URL；无需鉴权的本地接口可留空 API Key。
- API Key 只对本次启动有效，停止程序后不会保留。
- 程序启动后会自动打开浏览器；按 `Ctrl+C` 可停止运行。
- 如果助手已经在运行，启动脚本仍会先询问模式；直接回车可按本次选择重启，输入 `O` 则只打开现有页面。

如需临时改用其他端口，可以运行：

```powershell
.\start-assistant.cmd --port 4318
```
